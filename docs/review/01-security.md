# Phase 1 — Security + Privacy Review

Scope: public content/docs exposure, security headers, iframe sandboxing, proxy/redirect handling, API routes, outbound fetch timeouts, cookie banner necessity. Evidence from source at commit `87c1eea` and `docs/review/00-baseline.md` §5 (live header capture).

| ID | Severity | Area | Problem | Evidence | Fix | Effort |
|---|---|---|---|---|---|---|
| S1 | P1 | Headers | No CSP, HSTS, X-Frame-Options, X-Content-Type-Options, Permissions-Policy, or Referrer-Policy on the live site. `next.config.ts` only sets `Cache-Control`. | `00-baseline.md` §5 (live `fetch()` header dump); `next.config.ts:15-27` (`headers()` only returns `noLongCache`, no security headers) | Add a `headers()` entry (or middleware) emitting CSP (allow `frame-src` for the known `*.sacenpapier.org` subdomains used by `ProjectPreview`), `Strict-Transport-Security`, `X-Frame-Options: SAMEORIGIN` or CSP `frame-ancestors`, `X-Content-Type-Options: nosniff`, `Referrer-Policy` | S |
| S2 | P1 | API / SSRF-adjacent | `/api/infra/k3s` and `/api/infra/nodes` blindly proxy and re-publish whatever `https://homelabapi.sacenpapier.org` returns, with no field filtering, auth, or schema check — any internal data that endpoint ever adds becomes instantly public. | `src/app/api/infra/k3s/route.ts:1-6`, `src/app/api/infra/nodes/route.ts:1-6` (`fetch(...); const data = await res.json(); return Response.json(data, ...)`) | Define an explicit allow-listed response shape (pick named fields) instead of forwarding the raw JSON body | M |
| S3 | P1 | API reliability/DoS | None of the 4 route handlers (`backend-latency`, `infra/k3s`, `infra/nodes`, `pod`) set a fetch timeout or `AbortController`. A slow/hung upstream (homelabapi, xapi, poproomapi, botwhyapi, apercuapi) stalls the serverless request indefinitely, and `backend-latency`'s `Promise.all` means one hanging endpoint blocks all four. | `src/app/api/backend-latency/route.ts:9-18`, `src/app/api/infra/k3s/route.ts:2-4`, `src/app/api/infra/nodes/route.ts:2-4` — no `signal`/`AbortController` anywhere (verified via repo-wide grep, zero matches) | Wrap each `fetch` with `AbortSignal.timeout(2000-3000)` and catch the abort like the existing try/catch in `backend-latency` | S |

| S5 | P2 | Info disclosure | `/api/pod` returns the pod hostname and `NODE_NAME` env var to any unauthenticated caller — reveals internal k3s pod/node naming, useful for an attacker mapping the cluster. | `src/app/api/pod/route.ts:3-8` (`os.hostname()`, `process.env.NODE_NAME`) | Gate behind a build-time flag or strip to a static "ok" unless a debug header matches a secret | S |

| S7 | P2 | Recon surface | `/documentation` publicly details exact remote-access topology and SPOFs: "the Mac's own SSH config is effectively the map of who can reach whom," OPNsense as "a transparent bridge firewall — every packet on the LAN passes through it," Tailscale `tailscale serve` workaround specifics, and the exact CI/CD path (push to main → GitHub Actions → Trivy → Docker Hub → ArgoCD Image Updater → cluster rollout) with "no staging step in between." | `src/data/homelab.ts:62,160-166,341,384` | This is an editorial/content-risk tradeoff, not a code bug — flag for Jean-Michel to decide what level of topology detail he's comfortable publishing; at minimum consider redacting the "no staging step" and SPOF framing | M (content, not code) |

## Notes
- No CORS headers were found on any API route; all 4 are plain same-origin-default Next.js route handlers, so no explicit CORS misconfiguration — but combined with S4 (no rate limit), they're directly callable by anyone, not just the site's own frontend.
- `output: standalone` + `next start` mismatch (noted in baseline §2) is a deploy-correctness issue, not reviewed here as a security item.
- `npm audit`'s "1 critical severity vulnerability" (baseline §1) was not triaged in this pass — out of this reviewer's evidence set; recommend a separate dependency-audit pass.
